# Jornada do Design Thinking: Edeilson Contra o Mundo 2

Jogo educativo feito em Python com Pygame para auxiliar em estudos sobre Design Thinking.

## Desenvolvedor

Arthur Pereira Bispo

## Sobre o jogo

O jogador controla Edeilson em uma jornada pelo mapa, conversa com personagens e responde perguntas sobre as etapas do Design Thinking.

Após responder todas as perguntas, o jogador enfrenta o boss final "Tanilson".

## Etapas abordadas

- Empatizar
- Definir
- Idear
- Prototipar
- Testar

## Controles

- A/D ou setas: mover personagem
- Espaço: pular
- E: interagir
- Mouse: escolher respostas
- Enter: continuar após o feedback
